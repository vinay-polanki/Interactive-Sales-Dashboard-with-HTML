# Interactive-Sales-Dashboard-with-HTML

This project involves the development of an interactive, web-based Sales Performance Dashboard using HTML, JavaScript, and Plotly.js. The goal was to replicate a previously created Power BI dashboard in a browser-based format, enabling dynamic visualization and user interaction directly through a web interface.

The dashboard is designed to provide real-time insights from uploaded sales data in JSON format. It features five key visualizations: Sales Over Time, Profit by Category, Top Customers by Sales, Sales Distribution by Region, and Discount vs. Profit correlation. These visuals are essential for evaluating business performance, customer value, regional trends, and profitability patterns.

To enhance user experience, the interface incorporates a modern glassmorphism design, icy blue background, and responsive chart layout with 40% width padding. The dashboard allows users to upload their own data, which is instantly parsed and rendered without the need for backend services.

This HTML-based replication of a Power BI dashboard offers greater flexibility, portability, and accessibility, making it ideal for sharing insights in environments where desktop-based tools are not feasible.
